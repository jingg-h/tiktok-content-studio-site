TikTok Content Studio Local

TikTok Content Studio Local is a development project for creating, reviewing, and publishing short-form videos to TikTok.

Users can generate a short video draft from a text prompt, review the output, edit metadata such as captions and hashtags, and publish to their own TikTok account after authorization.

This project is currently in development and is used for testing TikTok Login Kit and TikTok content posting workflows.
